# ◈ IN-NO-V8 // WORLD PORTAL

This is the dedicated entrance hub for the in-no-v8 ecosystem. It features a high-fidelity, real-time split-flap display that synchronizes with the Studio Heartbeat pipeline.

## 🛠️ Components
- **`index.html`**: The primary landing page.
- **`flap.mp3`**: Custom mechanical sound effect for the Solari Board.

## 🚀 Live Deployment
- **Hosting**: Designed for root-level deployment (e.g., `in-no-v8.world`).
- **Real-time**: Communicates directly with Supabase via `supabase-js`.

## ⚙️ Key Configuration
The split-flap component is hard-coded with the project's Supabase credentials to ensure the feed remains live even when hosted on a standalone server.
